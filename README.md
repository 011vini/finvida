# 💰 Finvida (antigo Orcamente)

O **Finvida** é um sistema de gestão financeira pessoal desenvolvido para ajudar usuários a controlarem seus orçamentos, registrarem entradas e saídas e planejarem suas finanças de forma simples e intuitiva. 

Este projeto é um fork do repositório original [Orcamente](https://github.com/Espectrogamer16/Orcamente) criado em grupo para projeto final do 2 semestre da faculdade.

---

## 🚀 Funcionalidades (Planejadas / Em Desenvolvimento)

- **Controle de Receitas e Despesas:** Registro e categorização de ganhos e gastos diários.
- **Painel de Resumo (Dashboard):** Visualização clara do saldo atual e balanço mensal.
- **Gerenciamento de Categorias:** Organização de despesas por tags (ex: Alimentação, Lazer, Transporte, Moradia).
- **Histórico de Transações:** Consulta e filtragem de movimentações passadas.
